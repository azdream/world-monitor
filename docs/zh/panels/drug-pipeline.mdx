**Drug Pipeline** 面板回答一个问题：哪些新药可能迎来监管决定，大约在什么时候。它按决定最早可能落地的季度列出企业发起的 3 期试验，并单独列出近期 FDA 的首次批准。

## 面板显示内容

**Pipeline 标签页** — 每行对应一项 3 期（或 2/3 期）试验：

- **候选药物** — 试验中的主要在研药物。
- **药物类型徽标** — 小分子、抗体、ADC、细胞疗法、基因疗法、RNA、疫苗、多肽/蛋白或其他。
- **NEW / EXPANSION 徽标** — 候选药物尚未获批时显示 `NEW`；试验是为已获批药物测试新用途时显示 `EXPANSION`。
- **预计决定窗口**以及试验的主要完成日期。

各行按预计窗口的最早季度分组。两个下拉框可按药物类型和治疗领域筛选（每个选项显示数量），复选框可隐藏适应症扩展。每行链接到 ClinicalTrials.gov 上的试验页面。

**Recent approvals 标签页** — 最近 180 天内首次获批的 NDA 和 BLA，附带药物类型、新分子实体的 `NEW` 徽标，以及优先审评的 `PRIORITY` 徽标。

面板 id 为 `drug-pipeline`；规范组件为 `src/components/DrugPipelinePanel.ts`。

## 决定窗口如何估算

该窗口是启发式估算，不是已公布的日期：

- **最早** = 主要完成日期 + 10 个月（4 个月提交申请，6 个月优先审评）。
- **最晚** = 主要完成日期 + 22 个月（10 个月提交申请，12 个月标准审评，含受理期）。

监管机构不公开决定目标日期，申办方只在新闻稿和监管文件中披露，而本面板不采集这些来源。申办方公布的日期始终优先于估算值。试验也可能失败、推迟，或最终没有提交申请。

## 如何访问

- **Cmd+K**：输入 *drug pipeline*、*pharma* 或 *clinical trials*。
- **按变体的可用性**：在 **finance** 变体中默认启用；在 **full** 变体中已注册但默认关闭。

## 数据来源

两个 RPC 支持该面板：

- `GET /api/pharma/v1/list-drug-pipeline` — 接受 `modality`、`therapeutic_area`、`novel_only` 和 `limit`（默认 200，最大 500）。
- `GET /api/pharma/v1/list-drug-approvals`

种子器（`scripts/seed-drug-pipeline.mjs`）组合三个公开来源，均无需注册：

- **ClinicalTrials.gov API v2** — 主要完成日期落在过去 12 个月到未来 30 个月之间、由企业主导的干预性 3 期试验。这是唯一的硬依赖。
- **ChEMBL** — 用于名称匹配的分子类型（药物类型）和获批状态。ChEMBL 不可用时，药物类型回退到名称词干和注册库的干预类型。
- **openFDA `drugsfda`** — 首次批准的 NDA/BLA。`OPENFDA_API_KEY` 为可选项，只用于提高每日请求配额。openFDA 不可用时，批准标签页报告无数据，而不是空列表。

结果写入 Redis 的 `pharma:drug-pipeline:v1`，TTL 为 72 小时。发布的管线上限为 1,500 项试验，按时间由近到远排列，其中五分之一的名额保留给适应症扩展。

## 已知限制

- **批准列表缺少 CBER 产品。** Drugs@FDA 只覆盖 CDER，因此疫苗和细胞或基因疗法不会出现在批准标签页中，但会出现在管线标签页中。
- **药物类型部分为推断。** 只有公司代号且没有 ChEMBL 条目的候选药物，按注册库的 `DRUG` / `BIOLOGICAL` / `GENETIC` 标签归类，无法区分抗体与其他生物制品。
- **仅适用于美国的决定时间。** 审评周期假设基于 FDA，其他监管机构有所不同。

## 刷新频率

种子器在 health 种子包中**每日**运行。`api/health.js` 允许该键最长 48 小时（`maxStaleMin: 2880`），之后健康面才会升级告警。
